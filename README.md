# Fap_Apoint


 Para inicializar o terraform 

 no powersher o primeiro comnado é :
 terraform init
 
 Esse comando iniciará o projeto
 Cria a pasta .terrafom
 baixa o provider Docker
 prepara o ambiente 

Para verificar se o arquivo possui erros de sintaxe  o comando é :
terraform validate 

Para mostrar o que o arquivo pode fazer o comando é :
terraform plan 

O comando que cria um conteiner, baixa a imagem do ubuntu e registra o estado é :
terraform apply
